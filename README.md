# Merch App

Windows desktop app (WinUI 3) for merch rental management.

## Setup

1. Clone the repository
2. Copy `Config/appsettings.template.json` to `Config/appsettings.json`
3. Fill in your SharePoint and Azure AD credentials in `appsettings.json`
4. Install NuGet packages (restore automatically on build)
5. Run the app

## Requirements
- Visual Studio 2026
- Windows App SDK
- Microsoft 365 / SharePoint Online tenant
- Azure AD App Registration (see docs)
